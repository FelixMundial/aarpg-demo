# 2D AARPG

A small Godot 2D action RPG tutorial project, ported from GDScript to C# and based on [Michael Games' tutorial series](https://www.youtube.com/playlist?list=PLfcCiyd_V9GH8M9xd_QKlyU8jryGcy3Xa).

Open this folder with the Godot .NET editor (Godot 4.7.2) to explore and run the project. See [`docs/Project_Architecture.md`](docs/Project_Architecture.md) for an overview of its structure.
